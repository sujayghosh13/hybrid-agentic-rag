Hybrid dense and sparse retrieval, cross-encoder reranking, and a corrective loop that rewrites the query and retries when evidence is weak — instead of guessing.

query → route → hybrid retrieve → grade → answer (dashed = corrective loop)

Answer

Containers on the same physical host can communicate without exposing ports to the outside world by running them on the same user-defined Docker network. This lets containers resolve each other by name or IP directly — for example, two containers (web and db) on the same network can talk to each other without publishing ports, since the host can already route traffic between containers on that network. External access stays closed off; only the containers on the shared network can reach one another.
